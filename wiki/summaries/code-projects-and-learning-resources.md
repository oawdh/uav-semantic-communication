# 参考代码项目与学习资源

**Source**: `raw/notes/code-projects-and-learning-resources.md`

## Key takeaways

- 学习资源分为无人机控制、MCP 与模型交互、语义通信与语音处理、具身智能与视觉对齐四类。
- 推荐从 DJITelloPy 和 `drone-mcp` 入手理解基础控制与 MCP 工具封装。
- 语音侧可参考 Faster-Whisper，视觉侧可参考 CLIP、MobileSAM、YOLOv8 等思路。
- 四周学习路径从按键控制、MCP 示例、语音转意图逐步过渡到视觉约束执行。

## Core claims

这份清单适合作为学生入门路线，但需要被项目化：每个资源都应对应一个最小实验和一个 wiki 页面，避免停留在“收藏链接”。
